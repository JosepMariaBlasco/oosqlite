# ooSQLite Reference (DocBook source)

This is the source of the *ooSQLite Reference*, the manual published as
part of the ooRexx documentation. It was imported with its full history
from the ooRexx Subversion repository on SourceForge (`oorexx/code-0`,
path `docs/trunk/oosqlite`): 40 revisions, from r8516 (October 2012) to
r13206 (August 2026). Each imported commit keeps its original author and
date, and a `git-svn-id` line that points to its SVN revision.

The book is written in DocBook XML (`en-US/`). It is built with the ooRexx
documentation tools; the Rexx code in it is highlighted by `hldocprep`,
which needs the [Rexx Parser](https://github.com/JosepMariaBlasco/rexx-parser).
Building it here is still to be set up.

A built copy of the manual (December 2022, SVN r12583) is in
[`../oosqlite.pdf`](../oosqlite.pdf).
