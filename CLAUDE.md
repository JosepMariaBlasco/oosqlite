# CLAUDE.md — ooSQLite

ooSQLite connects ooRexx and SQLite: a native library (`src/ooSQLite.cpp`,
with SQLite compiled in) and an ooRexx package (`src/rexx/ooSQLite.cls`). It was
written by Mark Miesfeld inside the ooRexx project; this repository brings
it up to date and completes it. See `README.md`.

This repository is public: everything in it should read as project
documentation and code.
